Input columns

All inputs use the selected completed reporting period. Values must use each meter's configured units. Every physical meter needs a distinct Source Name; virtual meters calculate from accepted physical readings.

Data-quality rules

Counter samples must represent both period boundaries. Reset assumptions are reported with the run; unknown counter gaps are never scaled.

Output table

Create the results table using the setup guide's SQL script. Mapped streams write mass; mapped units write incoming and outgoing mass. All masses are kg per reporting period. Only determined results are written, in one transaction.

QUICK GUIDE

Build and reconcile a model

1

Place your units

Choose a pump, valve, heat exchanger, or another unit symbol from the toolbox. Drag it onto the canvas or click to add it. Add red inflow and outflow triangles at the model boundaries.

2

Connect the material paths

Drag a unit's right-hand output port to the next unit's left-hand input port. Each port accepts multiple streams. Or choose Connect, click the source, then click the destination.

3

Add meters and readings

Right-click a line, enter its material properties, and enable a meter. Use Hide line to simplify the view; open Hidden lines and choose Restore, or toggle Show hidden lines. Bridge bumps show crossings that are not connected. Open Measurements to enter its reading and uncertainty.

4

Run and review

Select a completed hour, day, shift, or batch above the model, then run reconciliation. Choose Earlier / custom to revisit a period. Model Management sets time zones, reporting boundaries, and late-data allowances. Compare measured and reconciled masses, review adjustments and data-quality warnings, and check which unmetered streams can be inferred.

Balance assumptions

All equipment symbols use total-mass conservation without accumulation or equipment-specific physics. Include all inflows, products, waste and vent paths. A closed balance estimates consistency; it does not prove every meter is correct.

Double-click a unit to change its name or symbol. Changing a symbol preserves its connections and readings. Double-click a line to edit it. Delete removes the selection. Scroll to zoom. Ctrl+Z undoes edits. Export a JSON file to keep a copy of your model.
